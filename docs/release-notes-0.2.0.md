# Release notes 0.2.0

- **HTTP API на FastAPI.** `python -m src.main_agent.app` теперь запускает Uvicorn на порту `8080`. Для запуска агента отправь `POST /api/v1/invoke` с query-параметром `message`. Проверка доступности сервиса — `GET /health`.
- **Структурированный ответ агента.** API возвращает идентификатор и статус запуска, провайдера и модель, историю ответов модели и результатов инструментов, число обращений к LLM, токены, стоимость и длительность.
- **Отдельный адаптер провайдера.** `AgentCore` получает провайдер при создании. `OpenRouterProvider` асинхронно обращается к SDK и возвращает `LLMResponse` с сообщением модели и метриками одного вызова. Агент суммирует токены и стоимость за весь запуск. OpenRouter — единственная реализация в этой версии.
- **UUID в пути сохранения.** Новые файлы сохраняются в `<workspace>/<run_id>/` по UUID из ответа API. В версии 0.1.0 подкаталог имел префикс `run-`. Старые каталоги по-прежнему доступны для чтения и поиска.

## Известные ограничения

- Используй `llm_config.stream: false`. Агентный цикл обрабатывает полный ответ модели.
- При нескольких шагах `duration` завышена, потому что прошедшее время от начала запуска прибавляется на каждом шаге.
- Если OpenRouter пропустит одно из суммируемых полей токенов или стоимости, запуск может завершиться HTTP 500.
