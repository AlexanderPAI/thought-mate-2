# Release notes

## 0.1.0

Первый релиз ThoughtMate2 — CLI-агента для задач по программированию.

- **Агентный цикл через OpenRouter.** Агент выполняет вызовы инструментов, передаёт их результаты модели и продолжает работу до финального ответа или достижения лимита шагов.
- **Файловые инструменты.** Агент рекурсивно ищет файлы по имени, читает и сохраняет текст в UTF-8. Доступ ограничен рабочими каталогами из конфигурации.
- **Отдельный каталог для каждого запуска.** При первой записи агент создаёт подкаталог `run-<id>/` внутри выбранного рабочего каталога и сохраняет туда файлы этого запуска. Поиск и чтение доступны во всём рабочем каталоге.
- **Логирование.** В консоли видны шаги агента, вызовы инструментов, ошибки и пути сохранённых файлов. На уровне `debug` также выводятся рассуждения модели или их сводка, если провайдер их вернул.
